
# Meus Sites Favoritos

## Sobre o projeto

Este projeto foi desenvolvido como atividade do curso técnico de Desenvolvimento de Sistemas.

O objetivo é criar uma página web para organizar e apresentar cinco sites favoritos, permitindo acessar cada um por meio de links.

## Tecnologias utilizadas

- HTML5
- CSS3

## Sites apresentados

1. Google - https://www.google.com
2. YouTube - https://www.youtube.com
3. Canva - https://www.canva.com
4. Wikipedia - https://www.wikipedia.org
5. Pinterest - https://www.pinterest.com

## Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Clique duas vezes no arquivo index.html.
4. A página será aberta no navegador.
